# hvadsigerislam.dk

Oplysningsside mod islamofobi: spørgsmål om islam som klikbare firkanter, med kildebaserede svar.

- Hele siden er `index.html` (ingen build). Vercel udgiver den automatisk ved hvert push til `main`.
- Hvert spørgsmål er en `<template id="..." data-tag="..." data-q="...">`-blok i `index.html`. Kopiér en blok for at tilføje et nyt kort.
- Et kort kan linkes direkte, fx `hvadsigerislam.dk/#frafald`.

Teksterne er udkast og skal gennemgås, før de fjernes fra udkast-markeringen.
